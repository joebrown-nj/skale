# Asset Workflow

Custom frontend source files live in `assets/`.

- Edit JavaScript in `assets/js/`
- Edit CSS in `assets/css/`
- Built runtime files are written to `public_html/js/*.min.js`
- Built runtime files are written to `public_html/css/*.min.css`

Commands:

- `npm run build:assets`
- `npm run watch:assets`

For the full source-to-output mapping and maintenance notes, see `assets/README.md`.
